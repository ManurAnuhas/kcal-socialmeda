Connect TikTok Business

TikTok requires a one-time token setup. Get your token from developers.tiktok.com, then paste it in the Manual Token tab.

📋 Steps to get TikTok Access Token:
  1. Go to developers.tiktok.com → Login
  2. My Apps → Select App → copy Client Key
  3. Use TikTok API Explorer to generate an Access Token
  4. Switch to ⚡ Manual Token tab → paste token
▶

Connect YouTube Channel

YouTube uses Google OAuth 2.0. Get your token from Google OAuth Playground, then paste it in Manual Token tab.

📋 Steps to get YouTube Access Token:
  1. Go to console.cloud.google.com → Enable YouTube API v3
  2. Create OAuth credentials → copy Client ID → save in Admin Settings
  3. Visit developers.google.com/oauthplayground
  4. Select youtube.upload → Exchange → copy token
  5. Switch to ⚡ Manual Token tab → paste token
